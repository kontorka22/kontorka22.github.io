# Поток РФ → ОАЭ

Мобильное приложение (PWA) для двоих: курс себеса и курс продажи USDT за операционный день,
по полной структуре из финмодели «Финмодель_поток_РФ_ОАЭ.xlsx», лист «Модель Рост».

## Что считает

Вводите поток за день (₽) — курс ЦБ подтягивается сам (на сегодня; на завтра — после ~15:30 МСК).

- **РФ — ООО:** агентское 1,5% (НДС 22% внутри), банк 0,5%, ФОТ 350 000 ₽/мес, налог на прибыль 25% → остаток ООО.
- **Гонконг:** транзит = поток − агентское. Себес: комиссия ГК 2%, курс ЦБ +1%. Продажа: 2,5%, ЦБ +1,3%.
- **Дубай:** номинал 5 000 $ + бух/аудит 5 000 $ в месяц — вычитаются из себеса.
- **Себес** = поток ÷ USDT к распределению. **Продажа** = поток ÷ выдача клиенту. **Прибыль** = разница в USDT.

Постоянные расходы (ФОТ, Дубай) делятся на число дней в месяце. Все параметры — во вкладке «Настройки».
Сохранённый день хранит снимок курса и параметров — задним числом не пересчитывается.

Проверка совпадения с таблицей: `npm test` (колонка E листа «Модель Рост» сходится до копейки).

## Синхронизация на двоих (Supabase, бесплатно)

1. Создать проект на supabase.com.
2. SQL Editor → выполнить `supabase.sql`.
3. Authentication → Users → Add user — два аккаунта (вы и партнёр). Затем отключить регистрацию новых.
4. Project Settings → API: скопировать Project URL и anon key.
5. В приложении: Настройки → Синхронизация → URL, key, email, пароль → Войти.

Без входа приложение работает локально на телефоне.

## Запуск локально

```bash
python3 -m http.server 8765
```

## Установка на телефон

Приложение должно открываться по https (любой статический хостинг). Дальше:
iPhone — Safari → «Поделиться» → «На экран Домой»; Android — Chrome → «Установить приложение».
