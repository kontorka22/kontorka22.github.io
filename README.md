# Поток РФ → ОАЭ

Мобильное приложение (PWA) для двоих: курс себеса и курс продажи USDT за операционный день,
по полной структуре из финмодели «Финмодель_поток_РФ_ОАЭ.xlsx», лист «Модель Рост».

## Что считает

Вводите поток за день (₽) — курс ЦБ подтягивается сам (на сегодня; на завтра — после ~15:30 МСК).

- **РФ — ООО:** агентское 1,5% (НДС 22% внутри), банк 0,5%, статьи расходов ООО, налог на прибыль 25% → остаток ООО.
- **Гонконг:** транзит = поток − агентское. Себес: комиссия ГК 2%, курс ЦБ +1%. Продажа: 2,5%, ЦБ +1,3%.
- **Дубай:** статьи расходов (номинал, бух/аудит…) — вычитаются из себеса.
- **Себес** = поток ÷ USDT к распределению. **Продажа** = поток ÷ выдача клиенту. **Прибыль** = разница в USDT.

Расходы — статьями на вкладке «Расходы»: каждый месяц / раз в год / разово. Ежемесячные делятся на дни
месяца и входят в себес дня; годовые и разовые попадают в отчёт своего месяца. Проценты — во вкладке «Ещё».
День — список поступлений; поле сверху работает и как калькулятор для клиента (₽ → USDT и обратно).
Сохранённый день хранит снимок курса и параметров — задним числом не пересчитывается.

Проверка совпадения с таблицей: `npm test` (колонка E листа «Модель Рост» сходится до копейки).

## Общий журнал на двоих (Supabase, бесплатно)

Вход по почте и паролю. Каждое изменение подписано именем: поступления, правки процентов,
статей расходов и плана видны в «Истории изменений» (кнопка с именем в правом верхнем углу).
Если оба вносят поступления в один день одновременно — они объединяются, ничего не теряется.

1. supabase.com → New project.
2. SQL Editor → вставить `supabase.sql` → Run.
3. Authentication → Users → Add user → два пользователя (Auto Confirm User). Затем отключить регистрацию.
4. Project Settings → API → Project URL и anon key вписать в `config.js`.

## Запуск локально

```bash
python3 -m http.server 8765
```

## Установка на телефон

Приложение должно открываться по https (любой статический хостинг). Дальше:
iPhone — Safari → «Поделиться» → «На экран Домой»; Android — Chrome → «Установить приложение».
